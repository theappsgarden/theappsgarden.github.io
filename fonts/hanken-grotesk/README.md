# Hanken Grotesk

Variable font by Hanken Design Co., self-hosted for the redesigned homepages. Secondary pages keep their existing font stack.

- Source: https://github.com/google/fonts/tree/main/ofl/hankengrotesk
- Original filename: `HankenGrotesk[wght].ttf`
- Local filename: `HankenGrotesk-Variable.ttf` (unmodified font data)
- License: SIL Open Font License 1.1, included in `OFL.txt`
- Weight axis: 100–900; normal style

No third-party font request is needed at runtime.
